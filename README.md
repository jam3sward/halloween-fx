Personal project for Halloween used to animate a skeleton, and to play sound effects.
Developed for Raspberry Pi.
 * Arms are raised/lowered by a geared motor (pulley with fishing line)
 * An optical sensor counts revolutions of the pulley
 * It serves a simple web page with buttons to raise/lower the arms, and play a sound effect

Installing the pre-requisites:
```
apt-get install python3-pip
apt-get install python3-pygame
```

Launching the server:
```
python3 server.py
```
